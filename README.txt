AI FASHION STUDIO — PORTFOLYO

Başlatma:
1. ZIP dosyasını çıkarın.
2. index.html dosyasına çift tıklayın veya VS Code ile klasörü açıp Live Server kullanın.
3. Yayına almak için klasörü Netlify Drop, Vercel veya kendi hosting hesabınıza yükleyebilirsiniz.

Düzenleme:
- İletişim e-posta adresini index.html içindeki hello@aifashionstudio.com alanından değiştirin.
- Galeri görselleri örnek görsellerdir; kendi AI üretimlerinizi eklemek için ilgili img src adreslerini assets klasörüne koyacağınız dosya yollarıyla değiştirin.
- Video bölümü şu anda video konseptlerini tanıtır; oynatılabilir video eklemek için video dosyası veya yayın URL'si gerekir.

Not: Fotoğraflar assets klasöründe yerel olarak paketlenmiştir; fotoğrafların görünmesi için assets klasörünü index.html ile aynı klasörde tutun. Portfolyo konsept sunumudur; gerçek müşteri işleri gibi gösterilmemelidir.
